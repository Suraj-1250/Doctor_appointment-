# Doctor Appointment System

A clean, responsive static frontend interface for a modern Doctor Appointment and Clinic Management System.

## 🌟 Features

- **Responsive Design:** Fluid layout that looks great on mobile, tablet, and desktop devices.
- **Dedicated Portals:** Separate login flows and experiences for Doctors and Patients.
- **Location-based Search:** Built-in forms to filter clinics and medical care by State and District.
- **Objective Driven:** Clean UI highlighting secure record keeping, 24/7 support, and cost-effective clinic visits.
- **No Backend Required for UI Demo:** Fully static HTML, CSS, and vanilla JS structure perfect for quick showcase deployments.

## 🚀 Local Setup

To run this project locally, simply clone the repository and open `index.html` in your browser. No build steps or package managers are required!

```bash
git clone https://github.com/Suraj-1250/Doctor_appointment-.git
cd Doctor_appointment-
```
Double click `index.html` to view the site.

## 🌐 Deployment (Render / Netlify / GitHub Pages)

This project has been optimized to deploy instantly on any static hosting platform.

### Deploying on Render:
1. Log into your Render dashboard.
2. Click **New +** and select **Static Site**.
3. Connect this `Doctor_appointment-` repository.
4. Leave the **Build Command** and **Publish directory** fields completely blank (or type `./`).
5. Click **Create Static Site**.
6. The site will be live within seconds!
